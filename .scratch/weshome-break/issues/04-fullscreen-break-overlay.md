# 04 — 全屏休息遮罩(多屏覆盖 + 占位视觉 + 倒计时数字)

**What to build:** 工作时长结束后,用户会在自己所有已连接的显示器上同时看到一个全屏遮罩窗口,该窗口层级高于常规应用(盖住 Dock 和菜单栏),内容目前是占位视觉(暂不是最终的五线谱音符效果),但会显示剩余休息时间的倒计时数字。休息时长结束后,所有屏幕上的遮罩自动关闭,应用回到下一轮工作状态。此时端到端可演示:等待一轮工作结束,自动进入全屏强制休息,倒计时结束后自动恢复工作。

**Blocked by:** 03 — 菜单栏接入调度器(自动运行 + 暂停/继续)

**Status:** ready-for-agent

- [x] 休息状态触发时,在每个当前连接的屏幕上各创建一个全屏遮罩窗口(AppKit `NSWindow`,窗口层级高于常规应用)
- [x] 遮罩内容用 SwiftUI View 承载,当前为占位内容(不要求是最终视觉效果)
- [x] 遮罩画面角落显示剩余休息时间的倒计时数字,随调度器状态实时更新
- [x] 休息时长结束后,所有屏幕上的遮罩窗口自动关闭,调度器转回「工作」状态
- [x] 新增/移除显示器等边界情况暂不要求特殊处理,只需覆盖当前已连接的屏幕集合
