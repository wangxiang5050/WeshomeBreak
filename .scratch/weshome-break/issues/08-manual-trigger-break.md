# 08 — 「立即开始一次休息」手动触发

**What to build:** 用户点击菜单栏菜单中的「立即开始一次休息」,会立刻进入和自动到点时一样的全屏休息遮罩流程(同样的多屏覆盖、同样的展示模式、同样的跳过/延迟按钮),不需要等待工作计时器走完。适合日常想主动休息一下,或者用来快速检验展示效果。

**Blocked by:** 04 — 全屏休息遮罩(多屏覆盖 + 占位视觉 + 倒计时数字)

**Status:** ready-for-agent

- [ ] 菜单栏菜单新增「立即开始一次休息」入口
- [ ] 点击后立即触发休息状态,复用自动触发所使用的同一套遮罩创建与调度逻辑
- [ ] 手动触发的休息结束后,正常回到工作状态并继续原有的计时节奏(不因手动触发而打乱后续排期之外的既定行为)
