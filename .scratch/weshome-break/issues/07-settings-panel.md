# 07 — 设置面板(时长、跳过/延迟、模式策略,持久化)

**What to build:** 用户点击菜单栏的「设置」入口,能打开一个设置面板,在里面调整:工作时长、休息时长、是否允许跳过/延迟(以及延迟时长数值)、展示模式选择策略(固定使用某个模式 / 随机轮换)。所有修改都会被保存下来,下次打开 App 时依然生效;修改后,下一轮计时或下一次休息会立即按新配置运行,不需要重启应用。

**Blocked by:** 03 — 菜单栏接入调度器(自动运行 + 暂停/继续)、05 — 跳过/延迟交互(核心重排逻辑 + 遮罩按钮)、06 — 展示模式协议 + 五线谱音符模式

**Status:** ready-for-agent

- [ ] 菜单栏菜单新增「设置」入口,点击后打开设置面板(Popover 或独立设置窗口)
- [ ] 设置面板可配置工作时长、休息时长(数值输入或滑块)
- [ ] 设置面板可配置是否允许「跳过」「延迟」,以及延迟时长数值
- [ ] 设置面板可配置展示模式选择策略:固定使用某个模式 / 随机轮换(当前只有一个模式时,选项仍需存在)
- [ ] 所有设置项通过 `@AppStorage`/`UserDefaults` 持久化,重启 App 后保留
- [ ] 修改设置后,当前/下一轮的工作时长、休息时长、跳过延迟行为、展示模式选择立即按新值生效
