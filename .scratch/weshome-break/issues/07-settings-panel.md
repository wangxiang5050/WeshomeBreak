# 07 — 设置面板(时长、跳过/延迟、模式策略、旋律库,持久化)

**What to build:** 用户点击菜单栏的「设置」入口,能打开一个设置面板,在里面调整:工作时长、休息时长、是否允许跳过/延迟(以及延迟时长数值)、展示模式选择策略(固定使用某个模式 / 随机轮换)、以及 **Melody Library**（导入/管理 MusicXML User Melody）与 **Melody Selection**（v1 手工选中当前旋律）。所有修改都会被保存下来,下次打开 App 时依然生效;修改后,下一轮计时或下一次休息会立即按新配置运行,不需要重启应用。

**Blocked by:** 03 — 菜单栏接入调度器(自动运行 + 暂停/继续)、05 — 跳过/延迟交互(核心重排逻辑 + 遮罩按钮)、06 — 展示模式协议 + 注册/选择、11 — MusicXML 导入门禁 + Melody Library / Selection 核心模型、12 — Staff Melody Scene（Verovio 展示 + 空态）
