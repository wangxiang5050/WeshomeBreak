# 09 — 全屏应用/勿扰模式检测与休息推迟

**What to build:** 当用户正在使用全屏应用(比如放映 PPT、看视频、开会)或系统已开启勿扰/专注模式时,原本该触发的休息提醒不会强行弹出打断,而是被推迟;等这些条件解除后,系统会尽快把这次被推迟的休息补上,而不会因为错过触发时机就彻底丢失这次休息。

**Blocked by:** 04 — 全屏休息遮罩(多屏覆盖 + 占位视觉 + 倒计时数字)、02 — 简单循环调度器(核心逻辑 + 单元测试)

**Status:** ready-for-agent

- [ ] 实现「当前是否有全屏应用在前台」的检测能力
- [ ] 实现「系统是否处于勿扰/专注模式」的检测能力
- [ ] 检测逻辑通过可注入的抽象暴露给 `GrillBreakCore`,不在核心逻辑中直接依赖具体系统 API,便于单元测试模拟两种环境状态
- [ ] 休息触发时命中上述任一条件,本次休息推迟,不弹出遮罩
- [ ] 条件解除后,尽快自动补触发这次被推迟的休息(不静默丢弃)
- [ ] 编写单元测试验证:命中条件时推迟、条件解除后补触发的行为,不依赖真实系统 API
