# 06 — 展示模式协议 + 五线谱音符模式

**What to build:** 休息遮罩不再是占位内容,而是展示真正的「五线谱音符」效果:标准五线谱居中显示,音符从屏幕四周以随机方向、随机时间间隔持续飘入,汇聚到中央谱线上排列成一段乐句;音符的音高在类似 C 大调音阶的范围内随机分布,让画面更像真实乐谱;整体采用深色夜间氛围配色(深色背景 + 白色/浅金色线条与音符)。同时,底层建立了一套可插拔的展示模式协议——即使当前只有这一种模式,后续新增模式也无需改动遮罩窗口或调度器的调用逻辑。

**Blocked by:** 04 — 全屏休息遮罩(多屏覆盖 + 占位视觉 + 倒计时数字)

**Status:** ready-for-agent

- [ ] `GrillBreakCore` 中定义 `BreakSceneMode` 协议(或等价命名),每种模式提供自身的展示视图与元信息
- [ ] 实现模式注册表,支持注册多个模式(当前只注册一个)
- [ ] 实现「固定选择」逻辑:按用户指定的模式返回固定结果
- [ ] 实现「不重复随机」逻辑:随机选择时排除上一次选中的模式;附单元测试验证多模式场景下不会连续两次选中同一模式
- [ ] 实现「五线谱音符」具体模式:标准五线谱(5 条横线)、音符从四周随机方向/时间持续飘入并汇聚排列成乐句、音高取自简单音阶(如 C 大调)范围内随机、深色夜间氛围配色
- [ ] 将遮罩窗口中的占位内容替换为「五线谱音符」模式的实际展示视图,保留角落倒计时数字
