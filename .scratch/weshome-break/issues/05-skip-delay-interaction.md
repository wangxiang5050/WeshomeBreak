# 05 — 跳过/延迟交互(核心重排逻辑 + 遮罩按钮)

**What to build:** 用户在休息遮罩上,把鼠标移动一下就能看到「跳过本次休息」和「延迟休息」两个按钮(平时默认隐藏,不干扰画面)。点击「跳过」会立即结束本次休息,并且下一次休息会重新计满一个完整的工作时长才触发。点击「延迟」会先关闭当前遮罩,过一段可配置的时长(默认 5 分钟)后重新弹出同一次休息;用户可以重复点击「延迟」,没有次数限制。

**Blocked by:** 04 — 全屏休息遮罩(多屏覆盖 + 占位视觉 + 倒计时数字)、02 — 简单循环调度器(核心逻辑 + 单元测试)

**Status:** ready-for-agent

- [x] `GrillBreakCore` 调度器新增「跳过」方法:调用后立即结束当前休息,下一次休息的目标时间重置为「当前时刻 + 完整工作时长」
- [x] `GrillBreakCore` 调度器新增「延迟」方法:调用后关闭当前休息,在「当前时刻 + 延迟时长」重新触发同一次休息;可重复调用,不限制次数
- [x] 为上述两个方法编写 Swift Testing 单元测试,验证重排后的目标时间符合预期,以及延迟可重复触发
