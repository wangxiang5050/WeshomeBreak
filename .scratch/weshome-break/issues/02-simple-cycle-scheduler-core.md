# 02 — 简单循环调度器(核心逻辑 + 单元测试)

**What to build:** 在 `GrillBreakCore` 中实现「工作 → 休息」的核心状态机:给定工作时长和休息时长,状态机能够在时间到达时正确地从「工作」转换到「休息」,再从「休息」转换回「工作」,循环往复。调度逻辑通过协议/策略方式设计,为未来新增其他调度模型(如工作时段模式、番茄钟预设)留出扩展点,新增策略不需要修改现有调用方代码。此阶段完全是纯逻辑,尚未接入任何 UI,通过单元测试验证行为。

**Blocked by:** 01 — 项目脚手架 + 菜单栏最小骨架

**Status:** ready-for-agent

- [ ] `GrillBreakCore` 中定义调度策略协议,「简单循环」作为该协议的一个具体实现
- [ ] 状态机支持可配置的工作时长与休息时长
- [ ] 工作时长到达后,状态机转换为「休息」状态;休息时长到达后,状态机转换回「工作」状态,可持续循环
- [ ] 提供暴露当前状态、剩余时间等信息的接口,供后续 UI 层消费
- [ ] 使用 Swift Testing 编写单元测试,覆盖工作→休息、休息→工作的状态转换正确性
- [ ] 测试只验证外部可观察行为(状态转换结果),不依赖具体 Timer/系统 API 实现细节
